# Sync Realty Website

**Connecting To Your Dream Space**

A premium, fully responsive real estate website for Sync Realty — a property consultancy based in Borivali West, Mumbai.

## Stack
- React 18 + TypeScript
- Vite (build tool)
- Tailwind CSS v4
- Framer Motion (animations)
- React Hook Form + Zod (form validation)
- Lucide React + React Icons (icons)
- shadcn/ui components

## Getting Started

### Install dependencies
```
npm install
```
Or with pnpm:
```
pnpm install
```

### Run development server
```
npm run dev
```

### Build for production
```
npm run build
```

## Key Files
- `src/App.tsx` — entire single-page website
- `src/index.css` — theme colors (Navy Blue, Gold, Inter font)
- `src/assets/` — hero, residential, commercial, pre-launch images
- `image_1780667661306.png` — Sync Realty logo

## Features
- Sticky navbar with mobile hamburger menu
- Hero section with luxury property background
- Trust indicators bar
- About section with company values
- 6 services cards with hover animations
- Why Choose Us section
- Property listings with Residential / Commercial / Pre-Launch filter tabs
- **Enquiry popup modal** — opens when clicking "Enquire Now" on any property card
- Auto-rotating testimonials carousel (4 reviews)
- Contact section with Google Maps embed
- WhatsApp contact form
- Floating WhatsApp button
- Instagram & Facebook social links
- Footer with quick links and contact info
